## 📌 Project Overview

The **Healthcare Product Portfolio & Revenue Analytics Dashboard** is an interactive business intelligence project designed to transform healthcare product data into clear, actionable insights.

The dashboard provides a consolidated view of **revenue performance, product portfolio composition, ATC (Anatomical Therapeutic Chemical) categories, and API intermediates**. Interactive filters allow users to explore the data at different category and product levels.

This project demonstrates practical skills in **Power BI, data modeling, KPI design, interactive reporting, and business-oriented data visualization**.

## 🎯 Objectives

- Analyze healthcare product portfolio performance.
- Understand revenue distribution across therapeutic categories.
- Identify high-contributing ATC categories.
- Analyze the distribution of API intermediates.
- Provide interactive filtering for category-level analysis.
- Convert raw healthcare data into business-friendly insights.

## 📊 Dashboard Highlights

### Revenue & Portfolio KPIs
- Total Revenue
- Total Categories
- Total Products
- Portfolio-level performance indicators

### Category Analysis
- Total Revenue by **ATC Category**
- Product/API distribution across therapeutic categories
- Identification of higher-contributing categories

### API Intermediate Analysis
- Count of API intermediates by ATC category
- Revenue contribution by API intermediate
- Interactive analysis using API Intermediate filters

### Interactive Features
- ATC Category slicer
- API Intermediate slicer
- Dynamic visual filtering
- KPI cards
- Donut charts
- Bar charts
- Business insight section

## 💡 Key Business Questions

This dashboard is designed to answer questions such as:

1. Which ATC categories contribute the most revenue?
2. How is the product portfolio distributed across therapeutic categories?
3. Which API intermediates have the highest representation?
4. How does revenue vary across different product/API segments?
5. Which areas of the portfolio may require further business attention?
